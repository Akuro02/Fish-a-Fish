# Fish-a-Fish
Jogo sério projeto da aula de jogos digitais criado utilizando a biblioteca libGDX/Java.

### Como rodar o jogo:
Requer JDK 11+ e a biblioteca libGDX.
```gradle run``` ou ```./gradlew run``` (se gerar o wrapper)


### Controles (Teclado)
- Menu: setas + ENTER, ou mouse
- ENTER: lança o anzol
- ESPAÇO: puxa o peixe
- ESC: volta ao menu
- R: repete a fase
