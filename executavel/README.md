# Fish a Fish

Jogo sério de reabilitação: pesque um peixe usando um cicloergômetro
(ou a tecla ESPAÇO no teclado).

## Dependência
Java 11 (ou mais novo). Para conferir a versão instalada:

    java -version

## Executar
Linux e Windows:

    java -jar fish-a-fish-1.0-all.jar

## Controles
- Menu: setas + ENTER, ou mouse
- ENTER: lança o anzol
- ESPAÇO (10 vezes): puxa o peixe
- R: repete a fase | ESC: volta ao menu
